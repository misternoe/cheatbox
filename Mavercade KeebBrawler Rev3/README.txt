/////////////
PRINTER SETTINGS
/////////////

Filament type: PLA not recommended! PETG recommended at a minimum. Black PETG-HF if trying to color match with the stock nylon buttons.

Infill: 80%, Gyroid

Layer Height: 0.16mm minimum

Printing orientation: User preference

Build Plate Adhesion: Glue is recommended for easier removal

Supports: Tree

Note: You may need to do some clean up on the stem mounts to be able to install properly
